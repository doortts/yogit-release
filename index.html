AI 가 해결한 충돌을 사람이 확인하고 적용합니다

  • 쓰고 있는 AI CLI 로 충돌을 해결합니다. Claude Code, Codex CLI, Antigravity CLI 나 직접 넣은 CLI 를 쓰던 로그인 그대로 써서 API 키가 필요 없습니다.
  • AI 는 충돌 구역마다 양쪽이 왜 바꿨는지 설명하고 추천을 고릅니다. 사람은 ours, theirs, 결과를 나란히 보는 3-way 화면에서 구역마다 확인하고 고른 뒤 적용합니다.
  • 작업은 임시 worktree 에서 하므로 적용 전에는 두 브랜치가 바뀌지 않고, 적용한 뒤에도 되돌릴 수 있습니다. 한 도구가 사용 한도에 걸리면 다음 도구가 이어 받습니다.
